learn-AI-DLCv2

AWS の AI-DLC（AI-Driven Development Life Cycle）v2 を学ぶための教材サイトです。同じテーマの教材が2冊あり、作り方が違います。読み比べると「AI に直接書かせる」と「AI-DLC のワークフローで作る」の差が見えます。

claude 版

/claude/
初版30ページClaude Code に直接依頼AI-DLC 2.7.1 時点の資料に基づく

「AI-DLC v2 の教材を作って」という1回の依頼から、Claude Code が調査・執筆・公開までを方法論なしで一気通貫に行った版です。

  • 第1部: AI開発の歴史と種類（5世代・5スタイル・失敗パターン）
  • 第2部: AI-DLC v2 の特徴（方法論 v1 → 実装 v2、エンジン、33ステージ、スコープ、エージェント、ゲート、監査、メリデメ）
  • 第3部: ハンズオン（express → bugfix → feature → 成果物の読み方）
  • 第4部: チーム導入、付録（用語集・コマンド・参考リンク）

注意: 執筆時点（2026-09-07）の 2.7.1 ドキュメントに基づきます。2.8.0 以降、インストール方法は dist/ のコピーから install.sh によるネイティブ aidlc コマンドと aidlc config に変わりました。最新手順は first 版を参照してください。

first 版

/first/
AI-DLC v2 で制作AI-DLC 2.8.2成果物・監査ログ同梱

AI-DLC v2（2.8.2）をこのリポジトリにインストールし、AI-DLC のワークフローそのものを回して作った版です。要件分析 → 作業単位への分解 → 章の設計 → 執筆 → ビルド検証 → 公開を、AI-DLC の承認ゲートと監査ログ付きで進めました。

  • AI-DLC v1/v2 を知らないエンジニアが読者。歴史・概念・特徴・ハンズオン
  • 各フェーズで一次情報（2.8.2 のドキュメントとコード）に照らして事実確認
  • この本自身を作ったときの AI-DLC の成果物（要件・Unit・監査ログ）を実例として収録

AI-DLC が出す質問には、人間の代わりに claude 版の内容を参照して回答しました。その判断ログも本文に含めています。
