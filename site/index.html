learn-AI-DLCv2

AWS の AI-DLC（AI-Driven Development Life Cycle）v2 を学ぶための教材サイトです。同じテーマの教材が2冊あり、作り方が違います。読み比べると「AI に直接書かせる」と「AI-DLC のワークフローで作る」の差が見えます。

claude 版

/claude/
初版30ページClaude Code に直接依頼AI-DLC 2.7.1 時点の資料に基づく

「AI-DLC v2 の教材を作って」という1回の依頼から、Claude Code が調査・執筆・公開までを方法論なしで一気通貫に行った版です。

  • 第1部: AI開発の歴史と種類（5世代・5スタイル・失敗パターン）
  • 第2部: AI-DLC v2 の特徴（方法論 v1 → 実装 v2、エンジン、33ステージ、スコープ、エージェント、ゲート、監査、メリデメ）
  • 第3部: ハンズオン（express → bugfix → feature → 成果物の読み方）
  • 第4部: チーム導入、付録（用語集・コマンド・参考リンク）

注意: 執筆時点（2026-09-07）の 2.7.1 ドキュメントに基づきます。インストール手順はその後の版で変わっています。2.8.2 に固定した手順と版の歩みは first 版（2.1・4.1）を参照してください。

first 版

/first/
AI-DLC v2 で制作AI-DLC 2.8.2 に固定20章 + 付録4全章に出典節

AI-DLC v2（2.8.2）をこのリポジトリにインストールし、AI-DLC のワークフローそのものを回して作った版です。意図の把握 → スコープ → チームの慣行 → 要件 → 設計 → 作業単位 → 計画 → 執筆 → 検査 → 公開を、質問ファイル・レビュアー・承認ゲート・監査ログ付きで進め、その記録を第 5 部に収めました。

  • 第1部: 読者の現在地（なぜ「方法論」の話になるのか）
  • 第2部: AI-DLC の概念（原典と実装、「v2」「v1」という言葉の位置づけ、2.8.2 が定義する用語）
  • 第3部: v2 の仕組み（インストール、エンジンとコンダクター、ステージ、スコープ、エージェント、ゲートと監査、学習ループ、Construction）
  • 第4部: ハンズオン（2.8.2 を版固定で導入し、最初の質問が出るまで。手順はクリーン環境で再現検査済み）
  • 第5部: ケーススタディ（この本の制作記録: 計画、レビューと差し戻し、記録の読み方、そして無人運転の限界）

AI-DLC が出す質問と承認には、依頼者の代理として claude 版と依頼文を根拠に回答し、その判断ログを記録に残しました。事実は 2.8.2 のドキュメントとコードだけで裏取りし、各章末の「出典」節から辿れます。

事実の裏取り執筆時点のドキュメントを参照タグ v2.8.2 のドキュメントとコード、同梱ランタイム、制作記録の 3 系統に限定し、章末の出典節と検査スクリプトで機械確認
