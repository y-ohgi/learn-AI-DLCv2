# はじめに

この教材は、**AI Agent（Claude Code / Cursor / Codex CLI など）は日常的に使っているが、「AI駆動開発の方法論」には触れてこなかったエンジニア**が、AWS の **AI-DLC（AI-Driven Development Life Cycle）v2** を理解し、自分の手で一周動かせるようになるためのものです。

## この教材のゴール

読み終えたときに、次の3つができる状態を目指します。

1. **説明できる** — AI駆動開発がこの数年でどう変わってきたか、その中で AI-DLC がどこに位置するのかを、同僚に3分で説明できる。
2. **判断できる** — 目の前のタスクに AI-DLC を使うべきか、素の Agent で十分か、判断の軸を持っている。
3. **動かせる** — Claude Code に AI-DLC v2 をインストールし、小さな課題を1本、ゲート承認まで通せる。

## 想定読者

| 前提 | 説明 |
| --- | --- |
| AI Agent の実務利用 | ✅ 必要。「Claude Code に指示してコードを書かせ、差分をレビューする」が日常であること |
| AI駆動開発の方法論の知識 | ❌ 不要。Spec-Driven Development も AI-DLC も知らない前提で書いています |
| AWS の知識 | △ あると理解が早いですが、必須ではありません。ハンズオンは AWS アカウントなしでも進められる構成にしています |
| 言語・フレームワーク | 不問。ハンズオンは小さな Web API を題材にしますが、言語は自由です |

## 読み方

- **第1部**は歴史と分類です。「なぜ手法が必要になったのか」という背景なので、急ぐ人は 1.3 の比較表だけでも構いません。
- **第2部**が本体です。AI-DLC v2 の設計を、方法論（v1）と実装（v2）に分けて解説します。
- **第3部**がハンズオンです。**3.0 の環境準備から順に進めてください。**
- **第4部**はチームへ持ち帰るための章です。1人で試すだけなら後回しで構いません。

所要時間の目安は、第1部+第2部の読み込みで **60〜90分**、ハンズオンで **2〜4時間**です。

## この教材のスタンス

AI-DLC は「AI にコードを書かせる速さ」を上げる道具ではなく、**AI に大量に作らせたものを人間が信頼できる状態に保つための枠組み**です。したがって本教材は、AI-DLC を礼賛せず、次の点も正面から扱います。

- 33ステージ・29ゲートという**儀式の重さ**と、それが正当化される条件
- 生成されたドキュメントが**誰にも読まれない書類の山**になるリスク
- 「AI が全部やってくれる」ではなく「**人間が決める箇所が明示的に増える**」という性質

> **注意** — AI-DLC v2 は活発に開発が進んでいるプロジェクトです。本教材は執筆時点（2026年9月）の 2.x 系ドキュメントに基づいています。ステージ数・エージェント数・コマンド名は将来変わる可能性があるため、必ず[公式リポジトリ](https://github.com/awslabs/aidlc-workflows)の該当バージョンのドキュメントも確認してください。数値や仕様の一次情報は付録Cの参考リンクにまとめています。
